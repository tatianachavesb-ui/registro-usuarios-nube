# Registro de usuarios en la nube (Flask + MariaDB + GitHub Codespaces)

Sin instalar nada: todo corre en el navegador.

1. Suba esta carpeta a un repositorio de GitHub.
2. Botón verde **Code → Codespaces → Create codespace on main**.
3. Espere a que termine la configuración (la base de datos se crea sola).
4. En la terminal: `python app.py`
5. Abra la pestaña **PORTS**: puerto 5000 = aplicación, 8080 = Adminer.
   Adminer: servidor `db`, usuario `estudiante`, clave `estudiante123`, BD `ingenieria_web`.
